## 1. 密码学哈希函数 (Cryptographic Hash Functions)

实验的第一部分重点在于理解哈希函数的特性，包括确定性、单向性、抗碰撞性以及最重要的**雪崩效应** 。

### 实验内容：基本哈希计算与性能对比

在 `basicHash.py` 中，`compute_hashes` 函数对比了 MD5, SHA-1, SHA-2, SHA-3 等算法 。

- **代码逻辑**：
  - 使用 `PyCryptodome` 库中的算法类（如 `SHA256.new(data)`）创建哈希对象 。
  - 通过 `hexdigest()` 获取十六进制摘要 。
  - 记录 `time.perf_counter()` 来对比不同算法的计算速度 。
- **观察结果**：虽然 SHA-512 输出长度更长（512 bits），但在 64 位系统上，它的计算速度有时甚至快于 SHA-256 。

### 实验内容：雪崩效应 (Avalanche Effect)

这是衡量哈希函数安全性的重要指标：输入发生微小变化，输出应产生剧烈且不可预测的变化 。

- **代码逻辑**（`avalanche_effect_test` 函数）：
  - 创建两个仅有 1 bit 差异的消息：`message1` 是 100 个 'A'，`message2` 将首字母改为 'B' 。
  - 将哈希值转换为二进制字符串，逐位对比差异 。
- **实验结论**：对于 SHA-256，仅仅修改一个字母，输出中就有超过 **50%（约 141/256 位）** 的位发生了变化 。

## 2. HMAC (基于哈希的消息认证码)

实验的第二部分展示了如何利用密钥和哈希函数同时实现**数据完整性**和**身份验证** 。

### 实验内容：基本消息认证

在 `HMAC.py` 中，`message_authentication_demo` 模拟了发送者和接收者之间的交互 。

- **代码讲解**：
  - **生成密钥**：使用 `secrets.token_bytes(32)` 生成 256 位的安全随机密钥 。
  - **计算 HMAC**：公式为 $HMAC(K, m) = H((K \oplus opad) \parallel H((K \oplus ipad) \parallel m))$ 。
  - **安全验证**：使用 `secrets.compare_digest()` 进行验证。这能防止**计时攻击（Timing Attack）**，因为它不会在发现第一位不匹配时立即停止，而是消耗固定时间完成比对 。

### 实验内容：篡改检测 (Tampering Detection)

这部分模拟了攻击者拦截并修改消息的场景 。

- **场景逻辑**：
  1. 原始消息：“在 0300 关闭系统” 。
  2. 篡改消息：“在 1300 关闭系统” 。
- **代码表现**：
  - 接收方收到篡改后的消息后，使用手中的密钥重新计算 HMAC 。
  - 计算结果（以 `7e48...` 开头）与随消息附带的原始 HMAC（以 `66b7...` 开头）完全不匹配 。
- **安全维护**：系统判定为“已检测到篡改并拒绝”，保护了指令的真实性 。
