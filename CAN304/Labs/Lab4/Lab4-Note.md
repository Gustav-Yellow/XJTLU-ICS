### 1. 同态加密与 CKKS 核心概念

教案首先打破了“数据可用性”与“隐私”之间的权衡 。

- **同态加密特性**：允许直接在加密数据上进行计算，处理过程中数据始终保持加密状态 。
- **CKKS 方案**：专门用于处理**实数（浮点数）**的近似计算 。
- **计算误差**：由于 CKKS 模拟了浮点数运算，解密后会存在极其微小的误差（通常 < 0.1%），这在实际应用中是可以接受的 。

### 2. 实验一：环境验证 (`minimal_test.py`)

该实验用于确保你的实验环境（TenSEAL, NumPy）配置正确 。

- **代码要点**：

  - 通过 `ts.ckks_vector` 将明文数组转换为密文。
  - 演示了**加法同态**：`ciphertext + ciphertext`。
- **实验预期**：你应该能看到解密后的结果与原始明文高度接近，并输出 `Setup verification: PASSED` 。

### 3. 实验二：加法与乘法同态 (`ckks_basic.py`)

此部分深入展示了 CKKS 的数学特性：$Enc(a) + Enc(b) = Enc(a+b)$ 以及标量乘法 。

- **核心操作**：
  - **加法**：`enc_a + enc_b` 实现了两个加密向量的逐元素相加 。
  - **标量乘法**：`enc_a * scalar` 模拟了将加密数据扩大特定倍数 。
- **关键代码参数**：
  - `coeff_mod_bit_sizes` 被增加到 `[60, 40, 40, 60]`，以支持多级乘法运算带来的深度消耗。

### 4. 实验三：综合应用 - 隐私安全医疗统计 (`ckks_app.py`)

这是本 Lab 的核心应用场景：三家医院希望在不泄露病人具体年龄的情况下，共同计算所有病人的平均年龄 。

- **业务流程设计**：
  1. **本地加密**：各医院在本地生成随机病人的年龄数据，并使用相同的上下文（Context）加密 。
  2. **本地聚合**：医院调用 `encrypted_ages.sum()`。注意代码中生成的 **Galois Keys** 是执行此类求和操作所必需的 。
  3. **安全汇聚**：研究员接收到各医院的**加密和**，通过 `total_encrypted_sum + enc_sum` 进行累加 。
  4. **最终解密**：研究员只解密最终的总和，再除以总人数得到平均值 。
- **代码亮点**：
  - 演示了真实场景下的协作：研究员从未接触过任何单体病人的原始数据，仅处理加密后的中间结果 。
